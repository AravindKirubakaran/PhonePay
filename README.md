📊 PhonePe Pulse Data Visualization DashboardProject OverviewThis project is a capstone initiative focused on leveraging real-world PhonePe Pulse data to build an interactive, multi-metric data visualization dashboard. The application uses Streamlit for the web interface, Plotly and Seaborn for dynamic visualizations, and connects to a MySQL database for data sourcing.The primary goal is to provide insightful views into key business metrics—specifically Total Registered Users, Transaction Amounts, and Insurance Data—across various geographical and temporal dimensions in India.✨ Key FeaturesDynamic Metric Selection: Easily switch between different data views (Users, Transactions, Insurance) directly from the sidebar.Geographical Mapping (Choropleth): Visualize metric counts and amounts across Indian states using an interactive Plotly Choropleth map.Time-Series and Distribution Analysis: Deep dives into data trends over years and quarters, including time-series charts, top N distributions, and correlation matrices.Interactive Filters: Use Streamlit's sidebar filters for Year, Quarter, State, and District to customize the data displayed.Robust Data Handling: Utilizes a dedicated Python service (db_service.py) to connect to a MySQL database, ensuring separation of data logic from the presentation layer.🛠️ Technology StackLanguage: PythonWeb Framework: StreamlitVisualization Libraries: Plotly, Seaborn, MatplotlibData Handling: PandasDatabase: MySQLConnectors: sqlalchemy, mysql-connector-python🚀 Setup and InstallationFollow these steps to get the project up and running on your local machine.1. PrerequisitesYou must have the following installed:Python 3.8+MySQL Server2. Clone the Repositorygit clone [https://github.com/your-username/phonepe-data-visualization.git](https://github.com/your-username/phonepe-data-visualization.git)
cd phonepe-data-visualization
3. Set up the DatabaseThe application connects to a MySQL database named phonepay.Create the Database:CREATE DATABASE phonepay;
Import Data: Use the provided data tables (map_user, map_map, map_insurance, etc.) to populate the database.(Note: The DataExtractorPhonePay.ipynb notebook likely contains the scripts you used to extract and load the data into MySQL.)Configure Connection: Update the config.json file with your MySQL credentials:{
  "db_username" : "your_mysql_user", 
  "db_password" : "your_mysql_password", 
  "db_host" : "localhost", 
  "db_port" : "3306", 
  "db_name" : "phonepay"
}
4. Install DependenciesInstall all required Python packages using the requirement.txt file.pip install -r requirement.txt
(Note: Ensure mysql-connector-python and sqlalchemy are installed for database connectivity.)5. Run the ApplicationExecute the Streamlit application from your terminal:streamlit run GUI.py
